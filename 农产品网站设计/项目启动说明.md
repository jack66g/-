# 农产品供需平台 - 项目文档

## 一、项目介绍

这是一个**宁波城乡农产品供需营销平台**，提供农产品展示、用户注册登录、商品管理、订单管理等功能。

### 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Node.js + Express |
| 数据库 | MySQL（registration_db） |
| 密码加密 | bcryptjs / SHA-256 |
| 前端 | HTML + CSS + JavaScript |

### 后端服务（8个微服务）

| 端口 | 文件 | 功能 |
|------|------|------|
| 3000 | server.js | 用户注册 + 健康检查 |
| 3001 | forget.js | 密码重置 |
| 3002 | mian.js | 用户登录 |
| 3005 | rootfirst.js | 管理员认证 |
| 3006 | endback.js | 商品新增/修改 |
| 3008 | yutaoyangmei.js | 商品搜索查询 |
| 3010 | detail.js | 商品详情 + 购买 |
| 3011 | Myproduct.js | 订单查询 |

---

## 二、启动方式

### 前提条件

- Node.js v22+ 已安装
- MySQL 本地运行（端口 3306）
- 执行 `用户信息数据库代码.txt` 中的 SQL 建库建表

### 一键启动

```bash
cd "after end"
npm install    # 首次
npm start      # 一键启动
```

看到全部 8 个 ✅ 即启动成功：

