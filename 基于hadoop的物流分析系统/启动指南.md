## 快速启动（完整流程）

### 第一步：启动 HDFS 服务

打开**两个**命令行终端（cmd 或 PowerShell），分别执行：

```bash
# 终端1：启动 NameNode
C:\hadoop\hadoop-3.1.3\bin\hdfs.cmd namenode

# 终端2：启动 DataNode
C:\hadoop\hadoop-3.1.3\bin\hdfs.cmd datanode
```

> **注意**：这两个窗口会持续运行，**不能关闭**。关闭则 HDFS 服务停止。

验证 HDFS 是否启动成功：

```bash
jps
```

正常输出应包含 `NameNode` 和 `DataNode` 两个进程：
```
35652 NameNode
34692 DataNode
xxxxx Jps
```

### 第二步：生成数据并上传到 HDFS

在项目目录下打开终端，运行：

```bash
cd E:\设计遗留文件\基于hadoop的物流分析系统
python data_generator.py
```

执行过程：
1. 清理 HDFS 上的旧目录 `/logistics`
2. 创建 `/logistics/historical` 和 `/logistics/forecast` 目录
3. 生成 8 个城市的仿真数据（订单、收入、热度）
4. 使用 LSTM 模型生成 2024 年预测数据
5. 将 6 个 CSV 文件上传到 HDFS

预期输出：
```

目录 /logistics/historical 已就绪
目录 /logistics/forecast 已就绪
1/1 ━━━━━━━━━━━━━━━━━━━━ 0s 301ms/step
上传 temp_orders.csv成功
...
✅ 增强版数据已成功上传至HDFS
```

> 耗时约 30~60 秒（含 TensorFlow 初始化 + LSTM 模型训练）。

## 常见问题

### 1. emoji 编码报错

```
UnicodeEncodeError: 'gbk' codec can't encode character '\u2705'
```

**解决**：执行脚本前设置 `PYTHONIOENCODING=utf-8`：

```bash
set PYTHONIOENCODING=utf-8 && python hadoop_analysis.py
```

### 2. HDFS 无法启动

**现象**：`jps` 看不到 NameNode/DataNode

**排查步骤**：
1. 确认 `JAVA_HOME` 环境变量正确：`echo %JAVA_HOME%`
2. 确认 `C:\hadoop\hadoop-3.1.3\etc\hadoop\core-site.xml` 和 `hdfs-site.xml` 配置正确
3. 查看 Hadoop 日志：`C:\hadoop\hadoop-3.1.3\logs\`

### 3. Git Bash 路径转换问题

Git Bash 会自动将 `/logistics` 转换为 Windows 绝对路径，导致 HDFS 命令出错。

**解决**：使用 cmd 或 PowerShell 运行 Python 脚本，或者在命令前加 `MSYS_NO_PATHCONV=1`：

```bash
MSYS_NO_PATHCONV=1 python data_generator.py
```

### 4. NameNode 处于安全模式

**现象**：HDFS 只能读不能写

**解决**：手动退出安全模式
```bash
hdfs dfsadmin -safemode leave
```

## 一键完整流程

在项目目录下，依次执行：

```bash
# 1. 启动 HDFS
start "NameNode" C:\hadoop\hadoop-3.1.3\bin\hdfs.cmd namenode
start "DataNode" C:\hadoop\hadoop-3.1.3\bin\hdfs.cmd datanode

# 等待 10 秒让 HDFS 就绪
timeout /t 10

# 2. 生成数据
python data_generator.py

# 3. 生成图表
set PYTHONIOENCODING=utf-8 && python hadoop_analysis.py

# 4. 打开看板
start 分析看板.html

# 5. 查看进程，手动关闭
jps
```
