# 基于Hadoop的物流分析系统

## 项目概述

本项目是一个基于 **Hadoop HDFS** 的物流数据分析与可视化系统。系统通过 Python 脚本生成仿真物流数据（订单、收入、运输热度），将数据存储到 Hadoop 分布式文件系统（HDFS）中，再通过数据读取和 matplotlib/seaborn 可视化生成分析图表，最终以 HTML 看板形式呈现分析结果。

## 功能模块

### 1. 数据生成模块
- **data_generator.py**：为 8 个核心城市（北京、上海、广州、深圳、成都、重庆、武汉、西安）生成 2023 年历史数据和 2024 年 LSTM 预测数据
- **buysthing.py**：扩展版，覆盖 10 省 30 个城市，生成按城市拆分的大规模仿真数据集

### 2. 数据分析模块
- **hadoop_analysis.py**：从 HDFS 读取数据，生成 6 张汇总图表
  - 2023/2024 各城市订单量柱状图对比
  - 2023/2024 各城市货运收入饼图对比
  - 2023/2024 月度城市运输热度热力图对比
- **buyanalysis.py**：生成每个城市 2023-2024 的月度订单趋势对比图

### 3. 可视化看板（5个页面）
- **分析看板.html**：汇总仪表盘，展示订单量、收入分布、热力分析的总览对比
- **订单分析.html**：30 个城市的订单趋势详情页，分省份展示
- **运输监控.html**：物流运输实时监控面板
- **路径规划.html**：物流路径规划界面
- **仓储管理.html**：仓储管理面板

## 数据说明

本项目使用**仿真数据**（非真实物流数据），通过以下算法生成：
- **订单量**：正态分布基础 + 正弦季节性波动 + 城市等级因子 + 随机噪声
- **货运收入**：对数正态分布 + 城市专属参数
- **运输热度**：城市基础值 + 周末效应（x1.5） + 周期性波动
- **LSTM预测**：使用 3 层 LSTM（128→64→32）+ 2 层 Dense，对 2024 年订单数据进行神经网络预测修正

## 注意事项

1. 所有数据均为算法模拟生成的仿真数据，仅供学习和演示使用
2. 系统依赖 Hadoop HDFS 进行数据存取，运行前需确保 HDFS 服务已启动
3. Windows 环境下运行 Python 脚本需设置 `PYTHONIOENCODING=utf-8` 避免中文/emoji编码问题
4. 每次运行数据生成脚本会生成不同的随机数据，图表结果会变化
