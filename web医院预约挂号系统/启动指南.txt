  仁和医院在线预约挂号系统 —— 启动指南
============================================================

【项目简介】
  一个完整的医院在线预约挂号 Web 系统，采用前后端分离架构：
  - 前端：纯 HTML/CSS/JS（leading end 文件夹）
  - 后端：Node.js + Express（after end 文件夹）
  - 数据库：MySQL 8.0

  功能包括：
    用户注册/登录、密码重置、科室选择、
    医生号源预约、人脸识别验证（百度AI）、
    挂号取消、管理员排班后台。

============================================================

【前置条件】
  1. Node.js 已安装（本项目使用 v22.14.0）
  2. MySQL 已安装并运行（默认端口 3306）
  3. 数据库 hospital_db 已创建（含三张表）

============================================================

【密钥与配置】
  所有敏感信息统一存放在 after end/.env 文件中：
    - DB_*          数据库连接信息
    - AES_KEY       数据加密密钥
    - BAIDU_API_KEY  百度人脸识别 API 密钥（如需使用人脸验证功能）

  该文件已加入 .gitignore，不会被提交到版本控制。
  如需分享代码，请先删除 .env 中的真实密钥信息。

【常见问题】
  Q: 端口 3000 被占用？
  A: 打开 .env 文件，修改 PORT=3000 为其他端口（如 3001），
     然后重新启动。同时需要修改所有前端 HTML 文件中
     的 API 地址（搜索 http://localhost:3000 替换）。

  Q: 数据库连接失败？
  A: 检查 MySQL 是否运行，以及 .env 中的数据库密码是否正确。

  Q: 页面打开后样式异常或脚本不运行？
  A: 请务必通过 http://localhost:3000/ 访问，
     不要直接双击 HTML 文件打开。

  Q: 人脸识别功能不可用？
  A: 在 .env 中配置有效的百度AI API密钥即可。
